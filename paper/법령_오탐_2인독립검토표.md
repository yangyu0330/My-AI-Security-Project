# 공식 법령 탐지 29건: 2인 독립 검토표

- 대상 분석: `paper/audit_public_law_hard_negatives.py`
- 집계 기준: `paper/public_law_hard_negative_audit.json`
- 원문 출처: 국가법령정보센터 LAW OPEN DATA 공식 XML
- 작성 기준일: 2026-07-26
- 현재 상태: 검토 패킷 준비 완료, 사람의 독립 판정은 미실시

이 표는 Layer 0가 공식 법령 조문 1,519개 중 탐지한 29건을 두 명의 검토자가 독립적으로 분류하기 위한 양식이다. 자동 분석에서 29건은 `dept` 18건, `nationality` 11건이며, 이메일·전화번호·주민등록번호·카드번호 형태는 발견되지 않았다. 이는 검토 안전성을 높이기 위한 기계적 사전 점검일 뿐, 29건이 모두 오탐이라는 사람의 판정을 대신하지 않는다.

## 1. 검토 원문 재현

저장소 루트에서 다음 명령을 실행한다.

```powershell
$env:PYTHONIOENCODING='utf-8'
python paper/audit_public_law_hard_negatives.py --review
```

출력 JSON의 `review_packet`에는 사례 ID, 법령명, 조문 위치, 원문 SHA-256, Layer 0 탐지유형·근거어와 공식 법령 원문이 들어 있다. 원문은 공개 법령이지만, 검토자는 실제 운영 로그나 개인정보형 문자열을 이 표에 복사하지 않는다. 각 검토자는 상대방의 판정을 보기 전에 자신의 판정표 사본을 완성하고 서명한 뒤 병합한다.

## 2. 판정 기준

각 사례에는 아래 셋 중 하나만 부여한다.

- `오탐`: 문맥상 식별 가능한 자연인에 관한 개인정보가 아니며, 일반 법률·기관·지명 표현을 PII로 탐지했다.
- `진성 PII`: 문맥상 식별 가능한 자연인과 관련된 실제 개인정보이므로 차단 대상이다.
- `판단유보`: 문맥만으로 결정할 수 없거나 법률·개인정보 전문가의 추가 판단이 필요하다.

두 검토자의 판정이 다르면 원문과 판정 근거를 함께 확인한 뒤 제3의 합의 판정과 이유를 남긴다. 합의 전에는 자동 탐지 29건을 “확정 오탐 29건”으로 표현하지 않고 “과잉차단 후보 29건”으로만 보고한다.

Cohen's κ는 두 검토자가 모든 사례를 독립적으로 판정한 뒤 계산한다. 한 검토자 또는 두 검토자가 모든 사례에 같은 범주만 사용해 기대일치 계산이 퇴화하면 κ를 억지로 제시하지 않고 `산출 불가(범주 변이 없음)`로 기록하며, 범주별 분포와 단순 일치율을 함께 보고한다. 표본이 29건이고 탐지된 사례만 포함한 조건부 검토이므로, κ나 합의 결과를 서비스 전체 오탐률로 일반화하지 않는다.
