## 2. 팀 내용 검증

### 분석·코드 담당

- [ ] 사후변형 정답 복원 순서가 타당하다.
- [ ] 복원 불가 36건을 제외한 이유가 재현된다.
- [ ] 동일 `pii_type`·동일 원천값 매칭이 의도대로 동작한다.
- [ ] 반복 변형을 원문 군집으로 처리한 것이 적절하다.
- [ ] bootstrap seed와 10,000회 반복 결과가 재현된다.
- [ ] 정규화만 된 출력은 비식별화 성공으로 세지 않는다.
- [ ] 저장 산출물의 사후 감사이며 현재 제품의 전향적 재실험이 아님이 명확하다.

### 통계 담당

- [ ] 전체·한국어·target-changing·target-preserving 분석집합 정의가 배타적이고 완전하다.
- [ ] 위험차의 단위가 `%`가 아니라 `%p`로 쓰였다.
- [ ] 신뢰구간은 원문 군집 단위 재표집에 대응한다.
- [ ] 3.93배 주장이 표본구성 교란 때문에 폐기된 판단에 동의한다.
- [ ] 표본 제외와 반복측정 구조가 한계에 충분히 반영됐다.

### 보안·제품 담당

- [ ] A/B/C/D 구성 설명이 실제 저장 설정과 일치한다.
- [ ] Layer 0가 “필요하지만 충분하지 않다”는 결론이 수치와 일치한다.
- [ ] Bedrock의 한국어 sensitive-information filter 지원 설명이 공식 문서와 일치한다.
- [ ] Presidio 지원 엔터티와 실제 recognizer/버전을 구분했다.
- [ ] LiteLLM에 개별 가드레일 탐지 성능을 잘못 귀속하지 않았다.
- [ ] 0/10,000 오탐을 실환경 0%로 일반화하지 않았다.
- [ ] 법령 29/1,519개의 어휘적 과잉차단 후보를 실서비스 오탐률로 일반화하지 않았다.
- [ ] 서비스 도메인 hard negative와 문맥 기반 완화가 후속 과제로 남아 있다.

### 범죄학·정책 담당

- [ ] 일상활동이론의 보호자 개념을 기술시스템과 동일시하지 않았다.
- [ ] “전이” 대신 “전술별 잔존 취약성”으로 한정한 것이 타당하다.
- [ ] 합성 우회율을 범죄율·피해율로 해석하지 않았다.
- [ ] 정책 제안이 실험에서 직접 확인한 범위를 넘지 않는다.
- [ ] 「범죄와 정책」의 심사기준인 참신성·독창성·필요성·방법·논리·근거를 충족한다.

### 법률 담당

- [ ] 개인정보 전체와 제23조 민감정보를 구분했다.
- [ ] 제71조 제4호, 제75조 제2항 제5호, 제64조의2의 요건을 과도하게 단순화하지 않았다.
- [ ] 인공지능기본법 제33조·제34조·제35조·제43조의 기능을 정확히 구분했다.
- [ ] 법률 제21311호 통합본의 7월 21일 표시와 인용 조문의 1월 22일 시행일을 구분했다.
- [ ] 기술적 미탐 하나가 곧바로 법 위반·제재를 확정하지 않는다고 명시했다.
- [ ] 정책 제언이 현행법 설명인지 입법론인지 구분된다.

### 편집 담당

- [ ] 제목·국문초록·영문초록·연구질문·결론이 같은 주장을 한다.
- [ ] 본문 인용과 참고문헌이 1:1로 대응한다.
- [ ] 표 번호·표 제목·본문 참조를 최종 양식에서 부여한다.
- [ ] 영문 제목·초록을 원어민 또는 전문 교정자가 검토한다.
- [ ] 개인정보형 원문 문자열이 문서에 노출되지 않는다.
