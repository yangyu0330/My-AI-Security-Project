## 1. 제3자 재검증의 가장 짧은 경로

저장소 루트에서 다음 명령을 실행한다.

```powershell
python paper/verify_final_paper_claims.py
```

스크립트는 네 개의 저장 평가 결과와 두 개의 `payloads_10k.json`, Layer 0 탐지기 코드를 읽어 다음 항목을 전수 재계산한다.

- 10,000건·95개 PII 유형·36개 변이 이름
- 원문 PII가 변이 입력에서 사라진 5,287건
- 최종 평가기로 추적 불가한 2,647건
- 원문 PII를 직접 추적할 수 있는 보수적 부분집합 4,713건
- 기존 3계층 미차단 1,063건과 Layer 0 추가 후 미차단 64건
- Layer 0만 추가 차단한 999건과 그 999건의 `BLOCK:[BLOCKED]`
- 원형·변이 사례의 미차단율
- 두 평가기의 A/B/C/D TRUE 판정 차이
- VIN 72개 행의 체크디지트
- L0·L4 지연시간과 평균비
- 동명 표본 파일의 10,000/3,538건 충돌
- 필수 이름·주소 코퍼스 부재
- 정규식 45개·키워드 카테고리 22개

정상일 때 마지막 줄은 다음과 같다.

```text
ALL ASSERTIONS PASSED
```

스크립트는 표준 라이브러리만 사용하고 네트워크 호출이나 파일 쓰기를 하지 않는다.

## 2. 최종논문의 중심 결론

최종 원고의 결론은 두 층위로 분리하였다.

### 직접 입증된 결론

1. 한국어 PII가 기존 Presidio·Bedrock·Lakera 계층을 차단되지 않은 채 통과할 가능성이 존재한다.
2. 원래 PII가 그대로 남아 판정이 확실한 범위에서, 변이 사례는 원형보다 기존 계층 미차단율이 높다.
3. 정규화 기반 Layer 0는 기존 계층이 놓친 사례를 입력단에서 추가 차단한다.
4. 따라서 Layer 0는 한국어 생성형 AI 서비스의 필수 심층방어 계층으로 배치할 필요가 있다.

### 아직 확정하지 않은 결론

1. 전체 10,000건에서 Layer 0의 정확한 탐지율
2. Layer 0와 LLM judge의 정밀한 효과크기·성능 순위
3. 기존 McNemar p-value를 이용한 전체 데이터의 우월성 주장
4. 실제 범죄 감소율·피해 감소율

이 구분은 Layer 0의 필요성을 약화하기 위한 것이 아니라, 검증 가능한 근거와 아직 라벨 복구가 필요한 수치를 분리하기 위한 것이다.

## 3. Layer 0 필요성의 재분석

### 3.1 분석집합

다음 조건을 만족하는 사례만 1차 분석에 포함하였다.

```python
case["pii_value"] in case["mutated"]
```

이 조건을 만족한 사례는 4,713건이다. 변이 후에도 평가 대상 PII가 입력에 문자 그대로 존재하므로 별도의 gold span 복원 없이 잔존을 직접 확인할 수 있다.

### 3.2 구성

- A: `Presidio PII` + `Bedrock Guardrail` + `Lakera`
- C: `korean-layer0` + A

### 3.3 결과

| 검증 항목 | 값 | 계산 위치 |
|---|---:|---|
| 보수적 분석집합 | 4,713 | `conservative_exact_subset.n` |
| A 차단 | 3,650 | `A_blocked` |
| A 미차단 | 1,063 | `A_unblocked` |
| A 미차단율 | 22.55% | `1063 / 4713` |
| C 차단 | 4,649 | `C_blocked` |
| C 미차단 | 64 | `C_unblocked` |
| C 미차단율 | 1.36% | `64 / 4713` |
| A만 차단 | 0 | `paired.A_only` |
| Layer 0 추가 구성만 차단 | 999 | `paired.C_only` |
| 둘 다 미차단 | 64 | `paired.neither` |
| 999건의 Layer 0 action | 전부 `BLOCK` | `layer0_actions_for_C_only` |
| 999건의 Layer 0 output | 전부 `[BLOCKED]` | 같은 항목 |

### 3.4 변이 효과

| 구분 | n | A 미차단 | A 미차단율 | C 미차단 | C 미차단율 |
|---|---:|---:|---:|---:|---:|
| L0 원형 | 1,246 | 89 | 7.14% | 7 | 0.56% |
| L1·L2·L4·L5 변이 | 3,467 | 974 | 28.09% | 57 | 1.64% |

변이/원형 미차단율 비:

```text
28.09 / 7.14 = 약 3.93
```

절대차:

```text
28.09% - 7.14% = 20.95%p
```

L3는 구분자 변경 등으로 원래 PII 문자열 자체가 달라지는 경우가 많아 이 보수적 분석집합에 포함되지 않았다. 따라서 3.93배는 전체 변이기법의 확정 위험비가 아니라, 정답을 직접 확인할 수 있는 범위에서의 보수적 기술 위험비다.

### 3.5 “유출 가능성”의 정의

최종논문에서 유출 가능성은 다음 상태를 뜻한다.

> 평가 대상 PII가 입력에 존재하고, 해당 가드레일 구성에서 차단·마스킹되지 않아 다음 처리 단계 또는 외부 모델로 전달될 수 있는 상태

실제 외부 전송 로그, 공격자의 이용, 정보주체의 피해를 관찰한 것은 아니다. 따라서 “실제 유출 사고가 22.55% 발생했다”고 표현하지 않고 “기술적 미차단 또는 유출 가능성”이라고 표현한다.

## 9. 남은 한계

최종논문은 현재 증거로 입증 가능한 Layer 0의 필요성을 결론으로 삼았다. 그러나 전체 10,000건의 변이 후 gold span이 없으므로 다음 작업은 여전히 필요하다.

1. 각 변이기의 gold span·canonical value·동치표현 생성
2. 하나의 mutation-aware canonical evaluator
3. 10,000건 전체 재라벨링
4. 최소 2명의 사람 검토자와 일치도
5. 전체 A/B/C/D 효과크기·95% 신뢰구간 재계산
6. 실제 비민감 한국어 hard-negative 오탐 평가
7. 필수 코퍼스·seed·SHA-256·라이선스 복구
8. 깨끗한 환경에서 원시자료부터 표까지 CI 재현

이 작업이 완료되면 보수적 4,713건 결론을 전체 데이터로 확장할 수 있다. 완료 전에는 “Layer 0가 필요하다”는 결론과 “Layer 0의 전체 정확한 탐지율이 얼마다”라는 결론을 구분해야 한다.
